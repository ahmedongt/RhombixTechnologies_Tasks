# Task 2: Version Control with Git & GitHub

## Overview
Demonstration of core Git commands, branching strategies, and Pull Request workflows for collaborative software development.

## Git & GitHub Commands Demonstrated
- `git clone`: Cloned the remote repository to the local environment.
- `git checkout -b feature/git-github-task`: Created and switched to a dedicated feature branch.
- `git add .`: Staged changes for commit.
- `git commit -m "..."`: Created atomic commits with descriptive messages.
- `git push origin feature/git-github-task`: Pushed local feature branch to GitHub.
- **Pull Request & Merge**: Executed a code review and merged feature changes into the `main` branch.
